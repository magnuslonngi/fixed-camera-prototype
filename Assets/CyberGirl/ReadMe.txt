================CyberGirl===============
Requires Unity 5.5.0 or higher.
Version: 1.4



This pack includes skinned FBX and 3ds Max source (biped) model of CyberGirl.
Includes:

- skinned FBX model;
- ready humanoid Avatar for Mecanim;
- 7 skin variations;
- 8K PBR texture atlas (for each skin);
- Girl mesh - 20248 tris;
- eye bones\skin added to skeleton;
- hair mesh.

Please Note:
- Girl package without animations;
- Designed for 2sided shader (included, Unity 5 standard);
- Max (8K) texture size should be adjusted in texture import settings.
